# MEXC: исследование для ИИ-сотрудника ASCN (12.10.2026)

Проверено: официальные доки MEXC (mexc.com/api-docs, mexcdevelop.github.io), анонсы MEXC, живые GET-запросы curl 12.10.2026. Регистраций, форм и ключей не использовали.

## 1. Брокерская и партнёрская программы

### Брокер (API / Independent / OAuth)
- **Как засчитываются ордера.** В заголовок каждого торгового запроса добавляется `source: <Broker_ID>`. Цитата из Broker FAQ / Onboarding Guidebook: «Brokers must add "Header" so that our backend can recognize your users». Пример: `POST https://api.mexc.com/api/v3/order` с заголовком `source`. **Один Broker_ID на спот и фьючерсы.** На старых mexcdevelop.github.io заголовок не описан, там есть только ошибка 506 «Unknown source of request».
- **Ключи существующих пользователей.** В модели API Broker это и задумано: «Users apply for API keys and give them to the broker, which places orders using its Broker ID and the user's API key». Значит, засчитываются ордера по собственным ключам обычных пользователей. Регистрация по нашей ссылке и субаккаунты не нужны: субаккаунты есть только у Independent Broker. В брокерских документах нет прямого ответа, считаются ли ордера, отправленные **без** заголовка. Без `source` ордер брокеру не засчитывается.
- **Доля брокера (Broker FAQ, API/OAuth, спот и фьючерсы):**
  - **40–60%** комиссии, если у пользователя нет аффилиата. Точную ставку назначает аккаунт-менеджер.
  - **20% фиксированно**, если пользователь уже привязан к аффилиату.
  - Выплата T+1. Проверка начислений: `GET /api/v3/rebate/taxQuery`.
- **Как подать заявку.**
  1. Основной аккаунт MEXC и заявка в Institutional Program через institution@mexc.com или Telegram @Mexc_Institution. Ответ за 5 рабочих дней, рассмотрение до недели.
  2. Что прислать: сайт, месячный объём, с какими биржами уже интегрированы, бизнес-email, основной UID, тип брокера, UID для получения ребейтов.
  3. Для OAuth дополнительно: URL логотипа и callback URL.
- **Требования.** Для API Broker указана аудитория «more than 500 people» (copy-trade платформы, боты, квант-платформы). У Independent Broker до 100 000 субаккаунтов, у остальных типов до 30.
- **Нюансы.**
  - На API не действуют скидки Web/App и 0-fee акции.
  - Пары Innovation Zone через API не торгуются.
  - В Guidebook ещё висят устаревшие строки «futures place/cancel suspended» и «BTC/ETH-USDT not via API». Обе отменены: фьючерсы открыты 31.03.2026, BTC/ETH через API доступны с 01.03.2026.
- Источники:
  - https://www.mexc.com/api-docs/broker/broker-faq
  - https://www.mexc.com/api-docs/broker/mexc-broker-introduction
  - https://www.mexc.com/support/articles/17827791529302

### Аффилиат / реферал
- **Ставка.** До **70%** (реферальная плюс суб-аффилиатская). По сторонним источникам базовая ставка около 40%, региональная около 50%. Распространяется на спот и фьючерсы.
- **Срок.** По официальной странице пожизненно («Permanent Commission Rights»). Сторонние сайты пишут про 1080 дней, не подтверждено.
- **Кто может участвовать.** Блогеры от 500 подписчиков, крипто-сайты, агентства.
- **Обязательства.** Продвигать ивенты MEXC не реже двух раз в месяц.
- **Выплаты.** Ежедневно в 0:00 UTC, уровни пересчитываются дважды в месяц.
- **Ссылка.** Персональная ссылка или invite-код. Формат обычно `https://www.mexc.com/register?inviteCode=<код>` или `.../acquisition/custom-sign-up?shareCode=<код>`. Для curl обе страницы отдают 403 из-за бот-защиты, точный формат берём из кабинета. Свой код можно получить через `GET /api/v3/rebate/referCode`.
- **Привязка существующих пользователей.** Работает только для новых регистраций по ссылке. Механизма перепривязки старых аккаунтов в документах нет: ручная привязка через тикет описана только для суб-аффилиатов.
- **Проверка рефералов.** `GET /api/v3/rebate/affiliate/referral` (только для аффилиата, SPOT_ACCOUNT_READ) отдаёт по рефералам `uid`, `inviteCode`, время приглашения, firstDeposit/firstTrade, объёмы и комиссию.
- **Запрещено.** Фишинг, перехват официального трафика, имитация сайтов MEXC, вводящая в заблуждение поисковая реклама. Явного требования раскрывать партнёрскую ссылку в правилах MEXC нет, но действуют законы о рекламе (см. §5).
- Источники:
  - https://www.mexc.com/support/articles/4415403871769
  - https://www.mexc.com/api-docs/spot-v3/rebate-endpoints/get-affiliate-referral-dataaffiliate-only

## 2. Публичный API (без ключа), проверено curl 12.10.2026

**Спот v3** (`https://api.mexc.com`):

| Эндпоинт | Поля ответа |
|---|---|
| `/api/v3/ticker/24hr?symbol=BTCUSDT` | `lastPrice`, `priceChangePercent` (доля: −0.0166 = −1.66%), `bidPrice`, `askPrice`, `volume`, `quoteVolume`, `count` (null) |
| `/api/v3/klines?symbol=BTCUSDT&interval=60m` | Массив `[openTime, o, h, l, c, vol, closeTime, quoteVol]` |
| `/api/v3/depth?symbol=BTCUSDT&limit=…` | `bids`, `asks`, `lastUpdateId` |

- В klines интервалы `1m/5m/15m/30m/60m/4h/1d/1W/1M`. Вариант `1h` возвращает ошибку `-1121 Invalid interval`.
- Список пар, доступных через API: `/api/v3/defaultSymbols`.
- Правила пар: `/api/v3/exchangeInfo`. Поле `status` здесь строка "1", типы ордеров `LIMIT/MARKET/LIMIT_MAKER`.
- С 06.2026 есть эндпоинт анонсов (новые листинги), с 12.2025 эндпоинт `/api/v3/symbol/offline` (делистинги).

**Фьючерсы** (`https://api.mexc.com/api/v1/contract/...`, с 12–19.01.2026 домен сменён с contract.mexc.com; старый домен 12.10.2026 ещё отвечал):

| Эндпоинт | Поля ответа |
|---|---|
| `ticker?symbol=BTC_USDT` | `lastPrice`, `bid1`, `ask1`, `fundingRate`, `indexPrice`, `fairPrice`, **`holdVol`** (OI в контрактах), `volume24`, `amount24`, `riseFallRate` |
| `funding_rate/BTC_USDT` | `fundingRate` (0.000014), `collectCycle` (8 ч), `nextSettleTime`, `max/minFundingRate` |
| `funding_rate/history` | История фандинга |
| `kline/BTC_USDT?interval=Min60&start&end` | Колоночные массивы `time/open/close/high/low/vol/amount` |
| `depth/BTC_USDT` | Уровни `[price, vol, count]` |
| `detail?symbol=` | `contractSize` 0.0001, `maxLeverage` 500, `takerFeeRate`, `makerFeeRate` |

- Отдельного эндпоинта Open Interest нет. OI берём как `holdVol × contractSize × цена`.

**Лимиты.**
- Спот: у каждого эндпоинта отдельный лимит 500 весов за 10 с по IP и по UID. При превышении HTTP 429, при повторных нарушениях бан IP от 2 минут до 3 дней.
- Спот: размещение и отмена ордеров делят общий лимит 12 запросов/с на UID.
- Фьючерсы: большинство приватных эндпоинтов 20 запросов за 2 с.
- WebSocket: 100 сообщений/с, до 30 стримов на соединение.

**Торговля фьючерсами через API (главное изменение).**
- **Ордера через API снова открыты с 31.03.2026, 06:00 UTC.** Changelog фьючерсов: «Futures Trading API maintenance ended; trading access reopened».
- Доступно всем пользователям с **KYC**. Без KYC права на фьючерсную торговлю не включить. Пары Innovation Zone исключены.
- Комиссии API отдельные, и их **дважды повышали**: на старте 0.01/0.05%, с 01.05 0.04/0.06%, **с 01.06.2026 maker 0.06% / taker 0.08%**. Для сравнения, в Web/App 0/0.01%.
- Страница mexcdevelop.github.io/contract_v1 устарела и до сих пор показывает «Under maintenance». Сторонние статьи 2026 года пишут то же самое по старой информации.

**Гео.** Сервис закрыт для пользователей из США и Канады. По большинству источников также Великобритания, Гонконг, Сингапур, Казахстан, Иран, КНДР, Куба, Судан, Крым и ОРДЛО. Индия приостановлена. Наши запросы прошли без блокировок. Обход через VPN грозит заморозкой аккаунта.

## 3. Приватный API с ключом пользователя

**Подпись запросов.**
- Спот: заголовок `X-MEXC-APIKEY`. Подпись HMAC-SHA256 от `queryString + body` в lowercase hex, параметры `timestamp` (мс) и `recvWindow` (≤60000, рекомендуется ≤5000).
- Фьючерсы: заголовки `ApiKey`, `Request-Time`, `Signature`, `Content-Type: application/json`. Подпись HMAC-SHA256(`accessKey + timestamp + paramString`). Для POST подписывается JSON-тело, для GET отсортированные параметры через `&`. `Recv-Window` по умолчанию 10 с.

**Спот:**
- `GET /api/v3/account` — балансы.
- `POST /api/v3/order` — ордер; для сухой проверки есть `POST /api/v3/order/test`.
- `POST /api/v3/batchOrders` — пакет до 20 ордеров.
- `DELETE /api/v3/order`, `/openOrders`, `/order/all` — отмена.
- `GET /api/v3/openOrders`, `/allOrders` (до 7 дней), `/myTrades` (до месяца).
- **Market TP/SL** — отдельный тип ордера с 25.11.2025. Полноценного OCO нет.
- `GET/POST /api/v3/apiKeyInfo` (с 2026 года) — проверить права ключа и задать IP-вайтлист.

**Фьючерсы:**
- `position/open_positions` — открытые позиции.
- `position/leverage`, `change_leverage` — плечо.
- `change_margin` — маржа.
- `funding_records` — история фандинга.
- `order/submit` — ордер.
- `stoporder/*` — TP/SL по позиции.
- `planorder/*` — триггерные ордера.
- Мультиактивный режим, STP и пакетные ордера добавлены в 2026 году.

**Копи-трейдинг.** Публичного API для копи-трейдинга нет, «AI Copy Trade» доступен только в Web/App.

**Права ключа.** SPOT_ACCOUNT_READ/WRITE, SPOT_DEAL_READ/WRITE, SPOT_TRANSFER_*, SPOT_WITHDRAW_*, CONTRACT_ACCOUNT_*, CONTRACT_DEAL_*. Рекомендация пользователю:
- режим «аналитика»: только `*_READ`;
- режим «торговля»: плюс `SPOT_DEAL_WRITE` и, при необходимости, `CONTRACT_DEAL_WRITE`;
- **права на вывод не давать никогда**.

Агент при старте проверяет права ключа через `apiKeyInfo` и **отказывается работать, если у ключа есть право на вывод**.

**IP-вайтлист.**
- До 30 ключей на аккаунт, до 10 IP на ключ.
- **Ключ без привязки к IP истекает через 90 дней.** Если у песочницы ASCN нет статического исходящего IP, пользователь получит ключ на 90 дней без вайтлиста. Агент должен напоминать о ротации ключа заранее, например за 7 дней.

## 5. Правила и риски

- **Злоупотребления.** MEXC может приостановить API за злоупотребления: массовые регистрации, фрод. Ставки ребейтов MEXC меняет без уведомления.
- **Конфликт с аффилиатом.** Если пользователь уже пришёл через другого аффилиата, брокер получает только 20%. Перепривязать пользователя нельзя.
- **Регулирование.** У MEXC нет лицензий первого эшелона. Эстония отозвала лицензию в 2023 году, SFC Гонконга внёс биржу в alert list в 2024-м, FCA выпускал предупреждение.
  - **Нельзя:** продвигать агента в закрытых юрисдикциях; помогать обходить гео-блокировки и KYC.
  - **Нужно:** проверять страну пользователя на онбординге.
- **Раскрытие.** MEXC этого не требует, но FTC (США), ASA/FCA (Великобритания), MiCA и законы ЕС о рекламе, закон РФ о рекламе (маркировка erid) требуют. **Агент обязан честно писать**, что ASCN получает вознаграждение от MEXC за регистрации и сделки, и что ссылка партнёрская.
- **Не инвестиционный совет.** Агент не даёт персональных инвестиционных рекомендаций. Каждый ордер требует явного подтверждения пользователя, кроме заранее заданных пользователем правил с лимитами.
- **Расходы пользователя.** Комиссии фьючерсов через API (0.06/0.08%) выше, чем в Web/App (0/0.01%). Пользователь должен знать, что торговля через агента дороже.

## 6. Рекомендация и MVP

**Модель заработка (два слоя):**
1. **Брокер — основной канал.** Подаём заявку как API Broker, потом отдельно как OAuth Broker.
   - Одна функция `mexc_request()` в общем модуле агента **всегда** ставит `source: <ASCN_BROKER_ID>` на все приватные запросы спота и фьючерсов.
   - Работает с ключами любых существующих пользователей: 40–60% комиссии, если у пользователя нет аффилиата, 20% если есть.
   - Broker_ID прошит в коде шаблона, а не в Secrets пользователя.
2. **Аффилиат — для новых пользователей.** Если у пользователя нет аккаунта MEXC, агент даёт ссылку `inviteCode` ASCN с явной пометкой «партнёрская ссылка».
   - Сверка «пришёл ли пользователь по ссылке» идёт на **бэкенде ASCN** через `/api/v3/rebate/affiliate/referral` с нашим ключом аффилиата.
   - Наш ключ аффилиата нельзя класть в песочницу пользователя.
   - На стороне агента можно получить UID пользователя (эндпоинт Query UID) и передать его на бэкенд ASCN.
3. **Позже — OAuth Broker.** Ключ пользователю вводить не нужно, подключение в один клик, ставка та же. Это лучше по UX и безопасности, но нужен callback на стороне ASCN.

**Техническая схема:**
- Хранение ключей:
  - `MEXC_API_KEY` и `MEXC_API_SECRET` лежат в Settings → Secrets.
  - Модуль `mexc.py` на стандартной библиотеке: подпись, `source`, повторы при 429, синхронизация `serverTime`.
- Проверка ключа на онбординге:
  - вызвать `apiKeyInfo`;
  - если есть право на вывод — блокировать работу;
  - показать срок жизни ключа, если IP не привязан;
  - для фьючерсов подсказать, что нужен KYC.
- Ордера:
  - перед каждым ордером валидация через `order/test` для спота, сводка с комиссией и подтверждение пользователя;
  - лимиты риска: максимум на сделку, на день и по плечу.

**MVP (5–7 функций):**
1. Портфель: спот плюс фьючерсные позиции, PnL, уровни ликвидации, утренний `.md`-отчёт.
2. Радар рынка: новые листинги и делистинги (анонсы, defaultSymbols), топ-движения, фандинг и OI (`holdVol`), алерты.
3. Спот-торговля голосом или текстом: лимит, маркет, Market TP/SL, отмена всех ордеров — каждое действие с подтверждением.
4. Фьючерсы: открыть или закрыть позицию, плечо, TP/SL через `stoporder`, контроль маржи, честное предупреждение о комиссиях API.
5. Стратегии-правила: DCA и сетка на споте, алерты по фандингу, всё в рамках лимитов.
6. Монитор ивентов: Launchpool, Kickstarter, Airdrop+, 0-fee акции — в виде напоминаний, без автоучастия.
7. Безопасность: проверка прав ключа, напоминание о ротации на 90-й день, гео-проверка, раскрытие партнёрства.

**Следующие шаги:**
1. Написать на institution@mexc.com: тип API + OAuth, UID получателя, прогноз объёма.
2. Подать заявку в Affiliate.
3. Уточнить у аккаунт-менеджера три вопроса:
   - засчитываются ли ордера с `source` для пользователей, привязанных к аффилиату ASCN (не получится ли двойного начисления);
   - нужен ли порог в 500 пользователей;
   - даёт ли ставка доступ к фьючерсам.
